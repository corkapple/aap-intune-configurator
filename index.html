Managed preferences

Ticked keys go into the configuration profile. Changing a value ticks it for you. Anything left unticked uses AAP's built-in default.

Supporting profiles

Optional payloads bundled into the .mobileconfig on the right. The Intune preference file only ever carries AAP's own keys.

Reporting

Intune custom attributes run a script and show one value per Mac under Devices › macOS › Custom attributes.

Import existing preferences

Paste a .plist, a .mobileconfig, or the keys-only XML used by Intune's preference file template. Recognised keys replace current values; everything else is listed so you can check it.
